# GEMS STEM Competition Web Application

Welcome to the official repository for our GEMS STEM Competition entry! This project presents an interactive web application designed to demonstrate STEM concepts using clean, responsive modern web technologies.

🌐 **Live Website:** [wsdcomp26.vercel.app](https://wsdcomp26.vercel.app)

---

## 🚀 Overview

This web project was created for the GEMS STEM Competition. Built using fundamental web technologies (HTML5, CSS3, and JavaScript), the application features an intuitive layout, responsive interface elements, and client-side logic to provide an engaging user experience for judges and visitors.

---

## ✨ Key Features

* **Interactive User Interface:** Built with responsive HTML5 markup designed to adapt seamlessly across desktop, tablet, and mobile displays.
* **Custom Styling & Layout:** Structured using modern CSS flexbox and grid layouts, styled with custom UI components and smooth transitions.
* **Client-Side Dynamic Logic:** Powered by vanilla JavaScript to handle dynamic DOM interactions, UI state changes, and event listeners efficiently without external dependencies.
* **Fast & Lightweight Performance:** Zero heavy bundle footprint, allowing fast initial page load speeds and smooth navigation.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Hosting & Deployment:** [Vercel](https://vercel.app)
* **Version Control:** Git & GitHub

## ⚙️ Local Setup & Quick Start

Since this application is built with standard web technologies, no build server or npm dependencies are required to preview it locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MCRTBP2006/gems-stem-competition.git
   ```

2. **Navigate to the repository folder:**
   ```bash
   cd gems-stem-competition
   ```

3. **Run the site:**
   * Open `index.html` directly in any standard web browser (Chrome, Edge, Firefox, Safari).
   * Alternatively, launch it using an extension such as **Live Server** in Visual Studio Code.
